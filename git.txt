# Push njFile-convertor to GitHub

## Prerequisites
- Have a GitHub account: https://github.com
- Git installed: `git --version`

## First Time Push

### 1. Create a new repository on GitHub
- Go to https://github.com/new
- Repository name: `njFile-convertor`
- Description: `Video and Audio File Converter using ffmpeg - supports CLI and GUI`
- Make it **Public** or **Private** (your choice)
- **DO NOT** check "Add a README file" or "Add .gitignore" or "Add license"
- Click **Create repository**

### 2. Initialize and push from your project folder

```bash
cd ~/Projects/njFile-convertor

# Initialize git repo
git init

# Add all files
git add .

# Commit
git commit -m "Initial commit: njFile-convertor - video/audio converter"

# Rename branch to main
git branch -M main

# Link to your GitHub repo (replace YOUR_USERNAME)
git remote add origin https://github.com/YOUR_USERNAME/njFile-convertor.git

# Push to GitHub
git push -u origin main
```

### Troubleshooting: "Updates were rejected" error

If the remote already has content (e.g. you added a README, LICENSE, or .gitignore on GitHub), you'll see:
```
! [rejected]  main -> main (fetch first)
error: failed to push some refs
```

Fix it by merging the remote history:
```bash
git fetch origin
git merge origin/main --allow-unrelated-histories --no-edit
git push -u origin main
```

### 3. Verify
- Open https://github.com/YOUR_USERNAME/njFile-convertor
- Confirm all files are visible

## Pushing New Updates (After First Push)

After you make changes to your code, use these commands to push updates:

### Quick push (all changes)
```bash
cd ~/Projects/njFile-convertor
git add .
git commit -m "Describe what you changed"
git push
```

### Push specific files only
```bash
git add file1.py file2.sh
git commit -m "Updated file1 and file2"
git push
```

### Check what changed before committing
```bash
git status          # See modified files
git diff            # See line-by-line changes
git diff --staged   # See changes that are staged for commit
```

### Common workflow
```bash
# 1. Check your changes
git status

# 2. Review the diff
git diff

# 3. Stage changes
git add .

# 4. Commit with a message
git commit -m "Fix: resolved crash on missing input files"

# 5. Push to GitHub
git push
```

### Pull first if you have conflicts
If someone else pushed changes or you modified the repo on GitHub directly:
```bash
git pull --rebase
# Resolve any conflicts if prompted, then:
git add .
git rebase --continue
git push
```
